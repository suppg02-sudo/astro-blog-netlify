## Welcome

This is the TELOS Blog - a local-first AI infrastructure documentation site.

### What is TELOS?

TELOS is the AI infrastructure constitution defining core principles:

- **Data Sovereignty** - All data stays local
- **Open Source** - Transparent, auditable code
- **Local-First AI** - Run AI on your own hardware
- **Deterministic Workflows** - Explicit and verifiable
- **Observability** - Full visibility into system behavior
