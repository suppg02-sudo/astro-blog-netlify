## Scoring Methodology

<details>
<summary>How confidence scores are calculated</summary>

Each item is scored on 5 weighted factors:

| Factor | Weight | What it measures |
|--------|--------|------------------|
| Domain safety | 30% | Schemas (safe) → agents (risky) |
| Change type safety | 25% | Schema alignment (safe) → agent rewrite (risky) |
| Rewrite safety | 20% | Review-only (safe) → large content change (risky) |
| Structured metadata | 15% | Has DNA/source fields (safe) → raw capture (risky) |
| Content size | 10% | Small (safe) → large (risky) |

Items scoring >= threshold are auto-approved. All others remain for manual review.
