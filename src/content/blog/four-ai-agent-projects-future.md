# Four incredible open source AI agent projects shaping the future

**Video URL**: https://www.youtube.com/watch?v=sXVbWkoCVaA  
**date**: March 28, 2026

---

## Overview

The AI agent landscape is evolving rapidly, and four groundbreaking open source projects demonstrate where the world is headed with autonomous AI systems. These projects represent the cutting edge of how humans will interact with, use, and leverage artificial intelligence in the near future.

---

## 1. GStack by Gary Tan (Y Combinator President)

**GitHub Stars**: ~50,000 (just weeks old)

Gary Tan, president of Y Combinator, premier startup accelerator in Silicon Valley, has open-sourced his entire methodology for building startups. Having invested in and overseen thousands of startups including Airbnb and DoorDash, Tan has distilled his expertise into a tool that gives solo developers the power of entire development teams.

### Key Features

- Simple copy-paste installation into Claude Code
 - Process-driven approach with YC office hours methodology
 - Specialized prompts for different roles (engineering manager, designer, debugger)
 - Fully open source

**url**: https://github.com/gary-tan/gstack

---

## 2. Hermes Agent by Nouse Research

**GitHub Stars**: 12,000+ (days old)

Self-improving agent framework similar to openClaw with terminal interface, multi-platform chat apps, and learning loops that improve over time.

### Key Features

- Terminal interface with multi-line editing
- Chat apps: Telegram, Discord, Slack, WhatsApp, Signal
- Self-improving learning loop
- OpenClaw migration support

**url**: https://github.com/nouse-research/hermes-agent

---

## 3. Superpowers by ora

**GitHub Stars**: 115,000+

Claude Code plugin with development workflows including brainstorming, TDD, git worktrees, plan execution, and code review.

### Key Features

- Brainstorming before coding
- TDD workflow enforcement
- Git worktree support for parallelization
- Plan execution and code review

**url**: https://github.com/ora/superpowers

---

## 4. Paperclip

**GitHub Stars**: 33,000+

Zero-human company orchestration with AI agents as CEO, CMO, CTO, and engineers.

### Key Features

- React UI dashboard for company management
- Ticketing system for work tracking
- Token usage tracking and budgeting
- Goal-driven agent coordination

**url**: https://github.com/paperclip-ai/paperclip

---

## Conclusion

These four projects show where AI agents are heading: from single tools to orchestrated teams to fully autonomous companies. This represents a fundamental shift in how we build and deploy software.
