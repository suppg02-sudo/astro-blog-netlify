## Introduction

A revolutionary approach is emerging for 2026: transforming educational content—books and YouTube videos—into reusable AI agent skills. This technique allows you to capture expert knowledge from product management courses, tutorials, and other educational resources, then convert them into intelligent capabilities that can be applied to real-world problems.

## The Core Methodology

### Step 1: Extract Content
Find high-quality educational content on YouTube or other platforms. Look for:
- Product management courses
- Technical tutorials
- Business strategy videos
- Domain expertise content

### Step 2: Get the Transcript
YouTube provides complete transcripts for most videos. Simply:
1. Navigate to the video
2. Scroll down to the transcript section
3. Select and copy the entire transcript (starting from the bottom makes this easier)

### Step 3: Create an Agent Skill
Paste the transcript into an AI platform (Claude, CodeX, or similar) and use the skill creator. The AI will:
- Understand the expertise embedded in the content
- Structure it into actionable knowledge
- Create a reusable skill that can analyze problems using that domain knowledge

### Step 4: Apply to Your Projects
Activate the skill and use it to analyze your own products, services, or projects. The agent can now think like an expert in that domain.

## Real-World Application: Harbor SEO Analysis

The video demonstrates this technique with Harbor SEO, a SaaS application. By converting a product management course into an agent skill, the creator discovered critical retention and UX issues:

### User Retention Issues Identified

**Lifecycle Emails Missing:**
- No pre-signup "aha moment" emails
- No getting started checklist
- No weekly recap emails
- Half of users lost after 14 days with no re-engagement

**Critical Insight:** "Silence kills ROI. A weekly 'here's what Harbor did for you' email with stats is the single biggest missing trigger."

### User Experience Problems

**Dead Ends in User Flow:**
- Article generation ends with no clear next steps
- No "write another article" button
- No "back to discover" option
- Library shows empty state with zero CTAs when no articles exist
- No "get writing" or clear guidance when empty

**Confusing Navigation:**
- Dashboard quick actions vs. workflow cards unclear
- Research keyword deep links to research URL in same tool (wasting cycles)
- Variable reward unpredictability in discovery feed

**Fundamental Gaps Identified:**
- Free token expiry invisible (50k tokens expire in 90 days, but UI never shows this)
- XP gains 100% predictable (no surprise celebrations)
- Article completion has zero celebration (core value component ignored)
- No achievement badges or milestone markers

### Actionable Improvements Generated

The agent skill suggested immediate fixes:
1. Add "write another article" button after completion
2. Create proper library empty state with clear CTAs
3. Show weekly challenge countdowns
4. Add celebrations in writer mode (not just dashboard)
5. Display token expiry dates in UI
6. Implement weekly recap emails with stats
7. Create pre-signup engagement sequences

## Why This Approach Works

### Stickiness and Retention
The video emphasizes that "stickiness" is the key differentiator between successful SaaS apps. You can have the best features, but if users don't feel good using your application and don't have reasons to return, you'll lose them.

### Expert Knowledge at Scale
Traditional product managers are incredibly valuable but can't analyze every detail at scale. Agent skills can:
- Deep-dive into each individual component
- Identify gaps humans might miss
- Generate comprehensive improvement lists
- Apply consistent expert frameworks

### Real Example: SEO Grove
The video shares a story about SEO Grove, a $500/month SaaS tool that clients abandoned immediately because "it's really hard to know what the hell is going on." Both SEO Grove and Harbor were built with the end product in mind, not the user journey. Agent skills can identify these friction points before users abandon your product.

## How to Get Started

1. **Find Expert Content**: Search YouTube for courses or tutorials in your target domain
2. **Extract Transcript**: Copy the complete transcript from the video
3. **Create Skill**: Use Claude, CodeX, or similar to convert transcript into a skill
4. **Apply Skill**: Use the skill to analyze your own projects with expert-level insights
5. **Iterate**: Create skills from multiple sources to build a comprehensive knowledge base
