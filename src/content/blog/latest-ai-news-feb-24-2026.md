## Top AI Stories

### 1. HuggingFace Agent Skills (5.1k stars)

HuggingFace released a new standardized format for AI/ML tasks including dataset creation, model training, and evaluation. The skills are interoperable with all major coding agents:

- **Claude Code** - Anthropic's CLI agent
- **OpenAI Codex** - OpenAI's coding assistant
- **Gemini CLI** - Google's command-line interface
- **Cursor** - AI-powered code editor

**How Skills Work**: Self-contained folders with `SKILL.md` files that package instructions, scripts, and resources together for AI agents.

**Available Skills**:
- HF CLI - Hub operations
- Datasets - Create and manage datasets
- Evaluation - Add eval results to model cards
- Jobs - Run compute jobs on HF infrastructure
- Model Trainer - Fine-tune LLMs with TRL
- Paper Publisher - Publish research papers
- Trackio - ML training experiment tracking

[GitHub: huggingface/skills](https://github.com/huggingface/skills)

### 2. Emdash - Open-Source Agentic IDE (1.6k stars, YC W26)

Emdash is a new open-source agentic development environment that lets you run multiple coding agents in parallel.

**Key Features**:
- Run multiple agents simultaneously with Git worktree isolation
- Supports 21+ CLI providers
- Linear, Jira, and GitHub Issues integration
- SSH remote development support

**Supported Providers**: Claude Code, Codex, Qwen Code, Gemini, Cursor, Cline, Amp, Auggie, Charm, Codebuff, Continue, Droid, GitHub Copilot, Goose, Kilocode, Kimi, Kiro, Mistral Vibe, OpenCode, Pi, Rovo Dev

**Architecture**: Provider-agnostic design that treats all CLI agents uniformly.

[GitHub: generalaction/emdash](https://github.com/generalaction/emdash)
