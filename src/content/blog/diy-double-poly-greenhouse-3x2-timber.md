# DIY Double-Poly Greenhouse: Build Your Own for Under £150

*3x2 timber frame with double-layer polythene - the budget grower's secret weapon*

A double-skinned polythene greenhouse outperforms cheap polycarbonate kits at a fraction of the cost. The air gap between layers provides excellent insulation, and the whole build costs less than a night out. Here's how to build one.

### Why 3x2 Timber?

| Property | 3x2 (75x50mm) | 2x2 (50x50mm) |
|----------|---------------|---------------|
| **Strength** | Excellent for this size | Marginal |
| **Cost** | ~£1.20/m | ~£0.80/m |
| **Screw holding** | Good | Limited |
| **Lifespan** | 10-15 years treated | 8-12 years |
| **Wind resistance** | Strong | May flex |

**Recommendation**: Use pressure-treated timber (tanalised). The extra £20 saves years of life.

## 🛠️ Build Steps

### Step 1: Site Preparation (1 hour)

```
Ground preparation:

1. Choose level site (or level it)
2. Clear vegetation
3. Mark out 6ft × 8ft rectangle
4. Options for base:
   
   [Paved base] - Best, most stable
   [Concrete blocks at corners] - Budget option
   [Timber base plate on ground] - Simplest, least durable
   [Raised bed base] - Combines growing space with structure
```

**Base plate method (simplest):**
- Lay 3x2 timber flat on ground
- Join corners with corner plates or half-lap joints
- Level with spirit level
- Anchor with ground spikes or concrete blocks at corners

### Step 2: Erect Corner Posts (30 mins)

```
Corner post detail:

     ┌─────────────────────┐  ← Top plate
     │                     │
     │  [3x2 post]         │
     │      │              │
     │      │  6ft to eaves│
     │      │              │
     └──────┴──────────────┘
            │
      [Base plate]

Joining method:
- Cut 45° angle at top of posts
- Screw through top plate into post end
- 3 screws per joint minimum
```

**Critical**: Check posts are vertical with spirit level. Use temporary bracing.

### Step 3: Add Wall Plates and Studs (1 hour)

```
Wall frame (side view):

┌──────┬──────┬──────┬──────┬──────┐  ← Top plate
│      │      │      │      │      │
│ Stud │ Stud │ Stud │ Stud │ Stud │
│      │      │      │      │      │
└──────┴──────┴──────┴──────┴──────┘  ← Base plate

Spacing: 2ft (60cm) centres
```

**Door opening:**
- 2ft 6in wide minimum
- Double up studs at door opening
- Add header across top of door

### Step 4: Roof Structure (1.5 hours)

```
Roof frame (bird's eye view):

        Ridge beam (8ft)
    ═════════════════════
    ╱ ╲   ╱ ╲   ╱ ╲   ╱ ╲
   ╱   ╲ ╱   ╲ ╱   ╲ ╱   ╲  ← Rafters at 2ft centres
  ╱     ╲     ╱     ╲     ╱
 ╱       ╲   ╱       ╲   ╱
╱─────────╲─╱─────────╲─╱
  Top plate (each side)

Rafter length: ~7ft (depends on overhang)
Rafter angle: 30° cut at top to meet ridge
```

**Rafter cutting:**
```
Rafter template (7ft):

     ┌─────────────────────────────┐
    /│                             │\
   / │        7ft span             │ \
  /  │                             │  \
 ────┴─────────────────────────────┴────
 ↑                                   ↑
30° plumb cut              Birdsmouth cut
(at ridge)                  (sits on wall plate)
```

**Purlins (cross-bracing):**
- Run 2 lengths of 3x2 across rafters (parallel to ridge)
- Provides attachment point for polythene
- Adds structural strength

### Step 5: Door (1 hour)

```
Door frame (2ft 6in × 5ft 10in):

┌─────────────────────┐
│ ┌─────────────────┐ │
│ │                 │ │
│ │   POLYTHENE     │ │
│ │                 │ │
│ │   (same as      │ │
│ │    walls)       │ │
│ │                 │ │
│ └─────────────────┘ │
│  [Hinge]   [Latch]  │
└─────────────────────┘

Frame: 3x2 with diagonal brace
Cover: Polythene stretched and battened
```

### Step 6: Double Polythene Skin (2-3 hours)

This is the secret sauce. Two layers with an air gap = excellent insulation.

```
Cross-section of double skin:

    ═══════════════════════  ← Outer polythene
           ↑
        2-3 inch air gap
           ↓
    ───────────────────────  ← Inner polythene
    ═══════════════════════  ← Timber frame
```

**Method:**

1. **Inner layer first:**
   - Roll out polythene inside frame
   - Pull tight and staple to inside of timber
   - Work from centre outward
   - Overlap at seams by 6 inches minimum

2. **Create air gap:**
   - Nail thin battens (1×0.5in) over polythene on outside of frame
   - These create the 1-2 inch gap

3. **Outer layer:**
   - Stretch second layer over battens
   - Pull VERY tight (polythene shrinks in cold)
   - Batten down with wider timber strips
   - Fold edges under for strength

**Critical tip**: Do this on a warm day. Polythene contracts in cold - if you install it loose, it will flap and tear.

### Step 7: Ventilation (30 mins)

**Minimum requirement**: 1 automatic vent opener in roof

```
Roof vent (simple version):

┌─────────────────────────┐
│                         │
│   ╔═══════════════╗     │  ← Vent flap
│   ║   VENT        ║     │
│   ╚═══════════════╝     │
│         ↑               │
│    [Auto opener]        │
│         │               │
└─────────────────────────┘

Size: 2ft × 2ft minimum
Hinged at top
Auto opener at side
```

**DIY vent:**
- Cut opening in roof
- Build frame around it
- Hinge a polythene-covered flap
- Install auto opener (£15-25)

## 🌡️ Double-Poly vs Single-Poly vs Polycarbonate

| Factor | Double Poly | Single Poly | Polycarbonate |
|--------|-------------|-------------|---------------|
| **Insulation** | Excellent (R-value ~2) | Poor (R-value ~0.8) | Good (R-value ~1.5) |
| **Heat retention** | 4-6°C warmer than outside | 1-2°C | 2-4°C |
| **Light transmission** | 85% | 90% | 82% |
| **Wind resistance** | Good if tight | Fair | Excellent |
| **Lifespan** | 4-6 years | 3-4 years | 10-15 years |
| **Cost** | Low | Lowest | High |
| **Repair** | Easy (patch kit) | Easy | Difficult |

**Double poly advantage**: The trapped air acts like double glazing. On a frosty night when it's -2°C outside, a double-poly greenhouse stays at 3-4°C. Single-poly would be 0°C.

## 🤖 ESP32 Automation Integration

The timber frame makes automation easy - you can screw into it anywhere.

### Simple Setup for DIY Greenhouse

```
ESP32 control box mounted to frame:

┌──────────────────────┐
│ [ESP32] [Relays]     │
│                      │
│ [DHT22 sensor wire]──┼──→ To sensor (mid-greenhouse)
│                      │
│ [Heater wires]───────┼──→ To tube heater
│                      │
│ [Fan wires]──────────┼──→ To extraction fan (in vent)
│                      │
└──────────────────────┘
       Screwed to timber frame
```

### Sensor Placement

| Sensor | Position | Mounting |
|--------|----------|----------|
| **DHT22 (temp/humidity)** | Centre, 4ft height | Screw small bracket to stud |
| **Soil moisture** | In grow bag | Push into compost |
| **DS18B20 probe** | Near plants | Bury 2in deep |

### Actuator Mounting

**Heater:**
- Mount tube heater low on frame
- Use pipe clips screwed to timber
- Run cable neatly along frame to ESP32 box

**Fan (in vent):**
- 12V PC fan in vent opening
- Screw directly to vent frame
- Pulls hot air out when triggered

## ⚠️ Common Mistakes

### Mistake 1: Loose Polythene

**Symptoms**: Flapping in wind, tears at fixings
**Cause**: Installed on cold day or not pulled tight enough
**Fix**: Re-stretch on warm day, use more battens

### Mistake 2: No Ventilation

**Symptoms**: Cooked plants, mould, mildew
**Cause**: Thought "polytunnels don't need vents"
**Fix**: Install at least one auto vent, open door on hot days

### Mistake 3: Inadequate Bracing

**Symptoms**: Frame racking in wind, eventual collapse
**Cause**: No diagonal bracing
**Fix**: Add diagonal timber braces to walls and roof

### Mistake 4: Poor Site Choice

**Symptoms**: Blown over, shaded, waterlogged
**Cause**: Didn't consider wind, sun, drainage
**Fix**: Relocate (hard) or add windbreak, drainage

## 💡 Pro Tips

1. **Build in spring** - Warmth makes polythene more pliable
2. **Over-order polythene** - Better to trim excess than come up short
3. **Use battens, not just staples** - Staples tear out in wind
4. **Double-diagonal-brace the frame** - One each direction on back wall
5. **Make the door bigger than you think** - Wheelbarrows need to fit
6. **Round all timber edges** - Sharp corners cut polythene
7. **Leave 6" polythene extra at ground** - Bury it for wind seal
8. **Add a kick board at base** - Protects polythene from feet/tools
