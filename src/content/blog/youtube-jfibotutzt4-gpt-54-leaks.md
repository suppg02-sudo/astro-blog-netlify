# GPT 5.4 Leaks: Confirmed Features and the Growing User Backlash

OpenAI's next major model, GPT 5.4, has been confirmed through multiple independent leaks from GitHub commits, error logs, and employee screenshots. The model introduces significant improvements including a 1 million token context window, an "extreme thinking" mode capable of reasoning for hours, improved long-running task reliability, and full-resolution image support. Simultaneously, a growing "Quit GPT" movement is seeing users migrate to Anthropic due to ethical concerns over OpenAI's Pentagon contracts.

## The Leaks: How We Know GPT 5.4 Is Real

Multiple independent sources have confirmed GPT 5.4's existence:

**GitHub Code Commits:** OpenAI engineer Curtis Fjord Hawthorne committed code with minimum model requirement set to "5.4" in the public CodeEx GitHub repository. The team made seven forced pushes over 5 hours to change the version from 5.4 to 5.3—clearly not a typo fix, but a fire drill.

**Employee Screenshots:** An OpenAI employee posted a screenshot showing GPT 5.4 in the model dropdown selector. Though deleted, screenshots were preserved.

**Error Logs:** Journalist Corey Nolles encountered an error message referencing model ID: `GPT 5.4-B-ARM1-10801p-codec-swip-EV3`, confirming the model is running on OpenAI servers.

**Journalistic Confirmation:** Stephanie Palazolo at The Information confirmed through OpenAI sources that GPT 5.4 is rolling out "soon."

## GPT 5.4 Key Features

### 1 Million Token Context Window

The most significant upgrade is the **1 million token context window**, a 2.5x increase from GPT 5.2's 400K tokens. This brings OpenAI to parity with Google's Gemini and Anthropic's Claude models, both of which already support 1M tokens.

While rumors suggested 2 million tokens, the confirmed figure is 1 million—still a massive improvement that enables processing entire codebases, books, or extensive document collections in a single context.

### Extreme Thinking Mode

GPT 5.4 introduces a new reasoning tier called **"extreme thinking"** that extends beyond the existing light/medium/high/extra-high reasoning levels.

**Key characteristics:**
- **Hours of reasoning** before returning an answer (not seconds or minutes)
- **Inference time compute** scaling significantly
- **Use cases:** Deep research tasks requiring extensive analysis

This is similar to Gemini's "pro mode" or "deep research mode" but focused on pure reasoning rather than tool calls and web searches. For the first time, you could ask a question and return hours later to find a deeply reasoned answer.

### Improved Long-Running Task Reliability

One of the most critical improvements addresses a major pain point with current AI agents: **memory and instruction retention over long workflows**.

**The problem:** Current models often "face plant" during extended tasks, forgetting user instructions or critical details. Wes shares examples:
- AI deleting emails after being told to confirm before deletion
- Models switching to different models mid-benchmark without permission
- Instructions given at the start of conversations getting lost

**The solution:** GPT 5.4 is specifically engineered to maintain context and remember details across many steps, making it significantly more reliable for:
- Coding agents working on multi-file projects
- Complex automation workflows
- Long-horizon tasks requiring hours to complete

### Full Resolution Image Support

Previous models compressed uploaded images, losing critical detail. GPT 5.4 supports **full resolution images** without compression for:
- Code screenshots
- Medical images
- Architectural drawings
- Technical diagrams and schematics

This preserves all pixel data for applications where fine detail matters.

### Priority/Fast Inference System

A new service tier system introduces **"standard" vs "fast"** options:

- **Fast tier:** Priority queue access via `/fast` command
- **Use case:** Real-time AI agents where latency is critical
- **Application:** Agents needing quick thinking and rapid response

This addresses a key limitation for production AI agents that need to think and act quickly.

## GPT 5.3 Instant: The Current Release

Before GPT 5.4, OpenAI just released **GPT 5.3 Instant** as the new default ChatGPT model with notable improvements:

- **27% fewer hallucinations**
- **Reduced "calm down" responses** (previously overused and perceived as fighting words)
- **Better writing quality**
- **Better search integration**
- **Fewer unnecessary caveats and refusals**

The focus was on making ChatGPT "less annoying to talk to"—addressing user frustrations with overly cautious or condescending responses.

## The Quit GPT Movement

Simultaneously with these technical advances, OpenAI faces a growing **user backlash**:

**The movement:** Users are cancelling ChatGPT subscriptions and switching to Anthropic's Claude

**The catalyst:** OpenAI's Pentagon/Department of War contracts

**The impact:** Estimated first-time download numbers show Anthropic now exceeding OpenAI

### Anthropic vs OpenAI Dynamics

The competitive landscape is intensifying:

- **Anthropic's Pentagon talks:** After initial rejection, Anthropic's chief is back in talks with the Pentagon about an AI deal
- **CEO's memo:** Anthropic's CEO attacked OpenAI's "mendacious Pentagon announcement," calling it designed to deceive "Twitter morons"
- **Government stickiness:** Many government departments want to keep using Claude, creating pressure to allow Anthropic back in

### OpenAI User Stats

- **Current:** ~910 million weekly active users
- **Target:** 1 billion by end of 2025
- **Status:** Slightly behind target
- **Impact:** GPT 5.1 and 5.2 reinvigorated growth after GPT5's perceived disappointment, but the Quit GPT movement is now causing losses

## OpenAI's New Release Strategy

OpenAI has learned from the GPT5 "letdown" and adopted a **monthly release cadence**:

**The problem:** GPT5 was awaited so long that expectations became unrealistic. When it arrived, many perceived it as a disappointment—even though it was exactly on the exponential scaling curve.

**The solution:** Regular incremental releases normalize progress and prevent overblown expectations.

**The pattern:** We're now seeing new versions roughly once a month, which OpenAI confirms is deliberate. This manages the hype/letdown cycle by making incremental improvements expected rather than revolutionary.

## The Bottom Line

GPT 5.4 represents OpenAI catching up to competitors on context window size while pioneering new territory in extreme reasoning duration and addressing the critical blocker of AI agent reliability. The focus on long-running task performance suggests OpenAI recognizes that reliability matters more than raw intelligence for production AI agents.

However, the simultaneous user exodus over ethics concerns demonstrates that **technical advancement and corporate reputation are increasingly intertwined**. The best model in the world won't matter if users don't trust the company behind it.

The monthly release cadence is a smart psychological strategy to manage expectations, but whether it can counteract the Quit GPT movement's momentum remains to be seen.
