# Four Open Source AI Agent Projects Shapping the Future

Four groundbreaking projects show where AI agents are headed.

## 1. GStack (Gary Tan/YC)

50K GitHub stars. YC President Gary Tan open-sourced his startup methodology. Simple Claude Code installation with specialized prompts for different roles.

## 2. Hermes Agent

12K stars. Self-improving agent framework with terminal interface and multi-platform chat apps.

## 3. Superpowers (ora)

115K stars. Claude Code plugin with TDD, git worktrees, brainstorming workflows.

## 4. Paperclip

33K stars. Zero-human company orchestration with AI agents as CEO, CMO, CTO.
