## Skill 1: Deep Research & Synthesis

### Main Prompt
```
Research the top five competitors in the AI avatar space.
Compare their pricing, features, target audience, and recent product launches.
Identify gaps in the market.
Format as an executive brief.
```

### Follow-up Prompt
```
Go deeper on competitor number three.
```

**Key behaviors:**
- Searches web in real-time
- Cites sources
- Synthesizes into actionable insights
- Remembers context and layers analysis

## Skill 2: Full Application Building (Artifacts)

### Main Prompt
```
Build me an interactive ROI calculator for my agency.
It should let users input their monthly ad spend, conversion rate, and average deal size,
then display projected revenue with a chart.
```

### Iteration Prompts
```
Make the color scheme darker.
```
```
Add a comparison mode.
```
```
Export the results as a PDF.
```

**What you get:**
- Working sliders
- Live-updating charts
- Beautiful design
- Fully functional in one message
- No code deployment needed

## Skill 3: Content Engine & Voice Matching

### Step 1: Voice Profile Creation
```
Analyze my writing voice.
Identify patterns in tone, sentence structure, vocabulary, and rhythm.
Create a style profile.
```

**Feed Claude:**
- Podcast transcripts
- Video scripts
- Best-performing posts

### Step 2: Content Multiplication
```
Using this voice profile, repurpose this 45-minute podcast transcript into:
- A YouTube script
- Five LinkedIn posts
- Three email sequences
- 10 tweet threads
```

**Result:** Every piece sounds like YOU wrote it—not generic AI output.

## Skill 4: Strategic Thinking Partner

### Main Prompt
```
I'm considering launching a new product line at a $2,000 price point
targeting small business owners.

Challenge this idea.
What could go wrong?
What am I not seeing?
```

**What Claude delivers:**
- Market positioning risks you hadn't considered
- Pricing questions against competitor benchmarks (real-time)
- Alternative launch strategies with phased pricing

**Key advantage:** No ego, available 24/7, holds entire business context.

## Skill 8: Creative Production

### Step 1: Brand Narrative
```
Develop a complete brand narrative for a product launch.
Include:
- The strategic story arc
- Origin story
- Problem-solution framework
- Emotional hooks
- Objection handling built into the narrative
```

### Step 2: Multi-Platform Variations
```
Now give me 10 variations of this narrative optimized for different platforms:
- LinkedIn thought leadership style
- Instagram caption style
- YouTube hook style
- Email nurture style
- Cold outreach style
```

**Result:** Same core narrative, 10 different executions, all voice-matched and platform-optimized.

## Pro Tips

### 1. Context Layering
Build on previous outputs:
```
Go deeper on [specific point]
```
```
Now apply this to [new context]
```
```
What would change if [variable]?
```

### 2. Format Specification
Always specify output format:
```
Format as an executive brief
```
```
Create a comparison table
```
```
Output as a numbered checklist
```

### 3. Real-Time Data
Leverage web search:
```
Compare to current industry benchmarks
```
```
Find the latest [information]
```
```
What are competitors doing now?
```

### 4. Voice Consistency
Always use voice profile:
```
Using my voice profile, [task]
```
```
Maintain my writing style: [task]
```

### 5. Iterative Refinement
Don't accept first output:
```
Make it more [adjective]
```
```
Add [feature]
```
```
Simplify for [audience]
```
