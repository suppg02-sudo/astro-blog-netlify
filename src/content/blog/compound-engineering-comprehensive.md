## Understanding Compound Engineering

Compound Engineering is a revolutionary methodology for building AI systems where each completed task makes the next one easier, leveraging prompts, flows, and sub-agents to compound learnings and create exponential productivity gains.

## 10 Core Concepts

### 1. Origin Story
Compound Engineering emerged from building Kora, an AI email assistant, where the creator discovered patterns that worked better for AI-assisted development.

### 2. Core Philosophy
The methodology is named "compound" because every piece of work completed makes the next task easier, similar to compound interest in finance.

### 3. Compounding Learnings
The system itself learns and compounds knowledge, meaning insights from previous tasks improve future task execution.

### 4. Plugin Ecosystem
Anthropic's plugin system enabled creation of a Compound Engineering plugin that now serves tens of thousands of users.

### 5. Paradigm Shift Required
Developers must rethink fundamental beliefs about software development, including who writes code and how it's reviewed.

### 6. Beliefs to Abandon
Key outdated beliefs include: code must be hand-written, every line must be reviewed, solutions must originate from engineers, and code is the primary artifact.

### 7. Planning Over Coding
The methodology emphasizes planning as more important than writing code, shifting focus from implementation to strategy.

### 8. Multi-Stage Development
The approach includes distinct stages of development, each with specific principles and practices for AI-assisted work.

### 9. Comprehensive Guide
A detailed guide at every.2guide/compateng provides philosophy, commands, beliefs, and practical implementation strategies.

### 10. Systemic Thinking
Success requires understanding the entire system and philosophy, not just using tools mechanically without comprehension.

---

## 5 Actionable Takeaways

1. **Embrace AI Code Generation** - Stop requiring hand-written code and trust AI to generate quality code, then focus on validation rather than line-by-line review.

2. **Prioritize Planning** - Invest more time in planning and system design before implementation; planning is more valuable than coding.

3. **Rethink Code Review** - Move from reviewing every line to sampling and validating outputs, trusting the AI-assisted process while maintaining quality gates.

4. **Build Feedback Loops** - Create systems where each completed task feeds learnings back into the system, creating exponential improvements over time.

5. **Study the Philosophy** - Before implementing Compound Engineering, understand the underlying philosophy and beliefs to avoid using tools mechanically without comprehension.
