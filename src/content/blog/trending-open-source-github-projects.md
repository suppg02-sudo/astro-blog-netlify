## Project Highlights

### 1. Superhum (Google DeepMind)
**Research datasets and tools for reasoning evaluation**

Superhum is an open research repository from Google DeepMind that hosts datasets, experiments, and supporting materials focused on advancing AI reasoning research. It provides benchmark data for studying complex reasoning tasks including mathematical and logical problem solving.

**Target Audience**: AI researchers building and evaluating reasoning systems

### 2. GA Connor
**AI agents automate repositories inside GitHub Actions**

GA Connor is a GitHub CLI extension and workflow framework that enables developers to create agentic automation for repositories using natural language markdown instead of complex CI configuration. It addresses rigid automation problems by allowing AI agents to analyze issues, review pull requests, and maintain projects directly within GitHub Actions.

**Key Features**:
- Natural language markdown workflow definitions
- Sandboxed execution environments with guard rails
- Integration with coding agents and existing CI pipelines

### 3. Grock 2 API
**Fast API server exposing Grock models through APIs**

Grock 2 API is a FastAPI-based backend service that provides OpenAI-style API endpoints for interacting with Grock models through web-compatible calls. It solves integration complexity by converting Grock web interactions into structured APIs.

**Key Features**:
- OpenAI-compatible API endpoints
- Support for chat, image generation, editing, and streaming responses
- Local or Docker deployment with MySQL, Redis, or PostgreSQL support

### 4. QMD
**Local CLI semantic search for personal knowledge**

QMD is a lightweight command-line search engine designed to help developers query documents, notes, and knowledge bases entirely on local machines. It addresses scattered personal data problems by indexing files and enabling semantic search without cloud dependency.

**Key Features**:
- Local indexing and processing
- Privacy-focused with no cloud dependency
- Modern retrieval approaches for improved relevance

### 5. Awesome LLM Apps
**Curated collection of real LLM application examples**

Awesome LLM Apps is a curated repository that aggregates practical applications built with large language models, agents, and retrieval systems. It acts as a reference library helping developers discover working implementations across OpenAI, Anthropic, Gemini, and open-source model ecosystems.

### 6. IGEN
**Open desktop co-work environment powered by AI agents**

IGEN is an open-source desktop productivity platform that acts as an AI co-worker environment for managing tasks and workflows. It addresses fragmented productivity tools by combining agents, workspace interaction, and automation into a single desktop experience.

### 7. World Monitor
**AI dashboard for real-time global intelligence monitoring**

World Monitor is a web-based monitoring platform that aggregates global news, geopolitical signals, and infrastructure information into a unified intelligence dashboard. It addresses information overload using AI-driven aggregation and analysis to present situational awareness in one interface.

### 8. GB Studio
**Drag and drop builder for retro handheld games**

GB Studio is a visual game development tool that allows users to create retro handheld-style games using a drag-and-drop interface instead of traditional coding. It addresses accessibility barriers by providing a structured visual editor.

### 9. Add MCP
**CLI tool for adding MCP integrations quickly**

Add MCP is a command-line configuration tool that helps developers quickly add Model Context Protocol (MCP) integrations to projects. It addresses setup friction by generating and managing MCP configuration through a simple NPX command.

### 10. Gondolin
**Secure MicroVM sandbox for autonomous AI agents**

Gondolin is an experimental Linux microVM sandbox designed to safely run AI agent-generated code with strict control over file system access, networking, and secrets. It acts as an agent execution environment that isolates workloads using lightweight virtual machines.

**Key Features**:
- Linux microVM sandbox for agent execution
- TypeScript control plane for permissions and runtime behavior
- Credential leakage prevention

### 11. Daylight Mirror
**Real-time external display bridge for Daylight devices**

Daylight Mirror is a desktop utility that turns a Daylight DC1 device into a real-time external display for a Mac. It addresses device compatibility by mirroring the Mac's native rendering output directly to the hardware at matching resolution.

### 12. XPipe
**Unified desktop hub for server and shell access**

XPipe is a desktop connection hub that lets developers access servers, containers, and remote environments through one unified interface built on existing command-line tools. It works on top of SSH, Docker, and other CLI utilities without requiring setup on remote machines.

### 13. Dozzle
**Lightweight web viewer for live Docker logs**

Dozzle is a web-based developer tool that streams Docker container logs in real-time through a simple browser interface. It solves monitoring problems for running containers without requiring heavy logging stacks.

### 14. Trip
**Self-hosted map tracker and travel planning platform**

Trip is a self-hosted web application that helps users visualize locations and organize travel plans on interactive maps. It works as a minimalist planner where points of interest, itineraries, and shared trip details are stored and managed privately without telemetry.

### 15. Happy
**Mobile and web remote client for coding agents**

Happy is a mobile and web companion tool that lets developers control coding agents (like Claude Code, Codex) from anywhere using an encrypted connection. It wraps existing CLI workflows so sessions can be resumed remotely from a phone.

### 16. PicoClaw
**Ultra lightweight personal AI assistant framework**

PicoClaw is a compact personal AI assistant built in Go and designed to run on minimal hardware with fast startup and low memory usage. It focuses on creating a self-contained agent system capable of operating within constrained environments.

### 17. Claw Compactor
**Deterministic workspace compression for AI agent context**

Claw Compactor is a Python tool that reduces AI agent context size by compressing memory files, transcripts, and workspace data using layered rule-based techniques. It solves token overhead by applying deterministic compression instead of calling language models.

### 18. AntFarm
**Multi-agent team orchestration for OpenClaw workflows**

AntFarm is an automation tool that creates coordinated teams of specialized AI agents working together inside OpenClaw environments. It defines roles such as planner, developer, tester, and reviewer that collaborate through structured workflows.

### 19. MDVI
**Full screen terminal markdown viewer with Vim navigation**

MDVI is a Rust-based CLI application that renders Markdown files into a polished full-screen terminal interface with Vim-style navigation. It uses a fast renderer and displays formatted text, syntax-highlighted code blocks, and images.

### 20. Clara
**OpenClaw skill enabling visual selfie responses for agents**

Clara is an OpenClaw skill that adds image generation and selfie-style visual responses to AI agents across messaging platforms. It installs into existing OpenClaw setups and connects to external image generation services to produce consistent character images based on reference personas.
