- Claude Code, Cursor, Windsurf, and Copilot lead in Western markets

## Western Providers

### Claude Code
**Pricing**: $20/mo (Pro), $100/mo (Max 5x), $200/mo (Max 20x), $150/user/mo(Teams)
**Key Features**: Terminal-native, 1M token context, Opus 4.5 reasoning
**Best For**: Senior engineers on complex codebases

**Strengths:**
- Deepest reasoning capability with Opus models
- 1M token context window holds entire codebases
- Terminal-native workflow fits power users
- Works alongside existing IDEs

**Limitations:**
- Token burn rate can surprise on Pro plan
- Locked to Anthropic models only
- Expensive at scale ($150/user/mo teams)

### Cursor
**Pricing**: $20/mo(Pro), $40/user/mo(Business), $200/mo(Ultra)
**KeyFeatures**: VS Code fork, Composer multi-file editing, Background Agents
**Best For**: Power users wanting flexibility

**Strengths:**
- Most polished multi-file editing (Composer)
- Multi-model support (GPT-5, Claude, Gemini)
- Largest community (1M+ users)
- Background Agents for async work

**Limitations:**
- Credit-based pricing unpredictable
- VS Code fork breaks some extensions
- Ultra tier expensive at $200/mo

### Windsurf
**Pricing**: $15/mo(Pro), $30/user/mo(Teams), $60/user/mo(Enterprise)
**KeyFeatures**: Cascade agentic engine, Memories system, Best value
**Best For**: Budget-conscious developers wanting agentic IDE

**Strengths:**
- Best price-to-feature ratio ($15/mo)
- Memories learns coding patterns over time
- Cascade for multi-file refactors
- App deployment (beta)

**Limitations:**
- Smaller community than Cursor
- No background agents yet
- Credit system can be confusing

### GitHub Copilot
**Pricing**: Free (limited), $10/mo(Pro), $19/user/mo(Business), $39/user/mo(Enterprise)
**KeyFeatures**: Deepest GitHub integration, Multi-model access, Agent Mode
**Best For**: GitHub-centric teams, enterprise

**Strengths:**
- Best price-to-value ($10/mo Pro)
- Tightest GitHub integration
- Multi-model access (Claude, GPT, Gemini)
- Coding agent turns issues to PRs

**Limitations:**
- Premium request metering complexity
- Multi-file editing less capable than Cursor/Windsurf
- Extension limitations vs forked IDEs

### Google Antigravity
**Pricing**: Free preview, $20/mo(Pro), Enterprise (custom)
**KeyFeatures**: Multi-agent orchestration, Built-in browser, Mission Control
**Best For**: Full-stack web development, multi-agent workflows

**Strengths:**
- True multi-agent parallelism
- Built-in Chromium browser for testing
- Mission Control UI for agent management
- Multi-model support (Gemini, Claude, GPT)
- Most generous free tier

**Limitations:**
- Still in beta (occasional UI stalls)
- Safety concerns (run in sandbox)
- No MCP support yet
- Pricing uncertainty post-preview

### OpenAI Codex
**Pricing**: $20/mo(ChatGPT Plus), $200/mo(Pro)
**KeyFeatures**: Cloud sandbox, o3 reasoning, Desktop app
**Best For**: ChatGPT users, cloud-based development

**Strengths:**
- Zero local setup (cloud sandbox)
- Bundled with ChatGPT Plus
- o3 reasoning model for planning
- Desktop app for multi-agent workflows
- Open-source CLI tool

**Limitations:**
- Walled garden (cloud sandbox)
- OpenAI models only
- No MCP support
- macOS only for desktop app

### Kiro
**Pricing**: $20/mo(Pro), $40/mo(Pro+), $200/mo(Power)
**KeyFeatures**: Spec-driven development, Hooks automation, AWS integration
**Best For**: Teams building production software, AWS-centric teams

**Strengths:**
- Structured specs before coding
- Event-driven hooks automation
- Steering files for team conventions
- MCP integration
- Most maintainable output

**Limitations:**
- Smaller community
- Spec-driven approach learning curve
- AWS ecosystem model lock

## OtherInternational Providers
其他国际提供商

### Aider - Open Source
**Pricing**: Free (bring your own API key)
**KeyFeatures**: Terminal-based, Multi-model, Open source
**Best For**: Developers wanting control, open source enthusiasts

**Strengths:**
- Completely free (BYO API key)
- Supports Claude, GPT, Gemini, local models
- Terminal-native workflow
- Active open source community
- Git-integrated workflow

**Limitations:**
- Requires API key management
- Less polished UI than commercial tools
- Terminal-only (no IDE)

**Availability**: Terminal, works with any editor

### Sourcegraph Cody
**Pricing**: Free tier, $9/mo(Pro), $19/user/mo(Enterprise)
**KeyFeatures**: Codebase-aware, Sourcegraph integration, Multiple models
**Best For**: Large codebases, Sourcegraph users

**Strengths:**
- Deep codebase understanding via Sourcegraph
- Multi-model support (Claude, GPT, Gemini, Ollama)
- Code context awareness
- Competitive pricing ($9/mo Pro)

**Limitations:**
- Requires Sourcegraph for best experience
- Smaller community than Cursor
- Less agentic than dedicated IDEs

**Availability**: VS Code, JetBrains, Web

### JetBrains AI

## Cost Optimization Strategies
成本优化策略
### Strategy 1: Right-Size Your Plan
**Light Usage** (< 20 agent requests/day): GitHub Copilot Pro ($10/mo) or Windsurf Free
**Moderate Usage** (20-50 requests/day): Windsurf Pro ($15/mo) or Cursor Pro ($20/mo)
**Heavy Usage** (50-100+ requests/day): Cursor Pro+ ($60/mo) or Claude Code Max 5x ($100/mo)
**Power Usage** (all-day): Claude Code Max 20x ($200/mo) or Cursor Ultra ($200/mo)

### Strategy 2: Combine Tools
Many developers use multiple tools:
- GitHub Copilot for inline completions (cheapest)
- Cursor/Windsurf for multi-file refactors
- Claude Code for architectural decisions
- Tongyi Lingma for Chinese-language work
- Aider for open-source control

### Strategy 3: Annual Billing
Annual billing saves 15-20% across all tools.

### Strategy 4: Context Management
- Start new conversations for new tasks
- Use file references instead of pasting code
- Write clear, specific prompts
- Exclude irrelevant directories from indexing
